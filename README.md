# FocusArena

A real-time competitive coding platform that evaluates problem-solving, focus, and efficiency.

## Tech Stack
- Backend: Django + DRF
- Database: PostgreSQL
- Frontend: React

## Setup

### Backend

1. Create virtual environment
2. Install dependencies:
   pip install -r requirements.txt

3. Configure .env file

4. Run migrations:
   python manage.py migrate

5. Run server:
   python manage.py runserver
